# 🏨 AI Hotel Booking System

## 📌 Project Description
A GUI-based Hotel Booking System built using Python and Tkinter.
It includes AI-powered hotel recommendations using cosine similarity.

## 🚀 Features
- Search hotels by city
- AI recommendation system
- Book hotels
- Leave reviews
- Dynamic rating update
- View booking history

## 🛠 Technologies Used
- Python
- Tkinter
- Pandas
- NumPy
- Scikit-learn

## ▶ How to Run

Install dependencies:
pip install -r requirements.txt

Run:
python hotel_booking_ai.py
