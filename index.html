🏨 AI Hotel Booking System

Smart hotel recommendations using AI

📌 About Project

This project is a GUI-based hotel booking system built using Python and Tkinter. It includes AI-powered hotel recommendations using cosine similarity.

🚀 Features

  • Search hotels by city
  • AI recommendation system
  • Book hotels
  • Leave reviews
  • View booking history

🛠 Technologies Used

Python, Tkinter, Pandas, NumPy, Scikit-learn
