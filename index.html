🏨 AI Hotel Booking System

Smart hotel recommendations using AI

📌 About Project

A GUI-based hotel booking system built using Python and Tkinter. It uses AI (cosine similarity) to recommend the best hotels to users.

🚀 Features

  • Search hotels by city
  • AI-based recommendations
  • Hotel booking system
  • User reviews and ratings
  • Booking history tracking

🛠 Tech Stack

Python, Tkinter, Pandas, NumPy, Scikit-learn
